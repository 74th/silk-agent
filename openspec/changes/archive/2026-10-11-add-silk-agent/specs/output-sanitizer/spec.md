# Spec Delta

## Purpose

エージェントの出力をユーザへ表示する前にModel Armorで検査し、個人情報はマスクして表示し、それ以外の有害な出力は表示しない。

## ADDED Requirements

### Requirement: 表示する出力はすべて検査する
システムは、チャネルへ表示するエージェント由来のテキスト（エージェントの応答、ツールの引数・結果の要約、アップロードするテキストファイル）を、表示する前にModel Armorのテンプレート`projects/nnyn-dev/locations/us-central1/templates/simple`で検査しなければならない (SHALL)。検査前のテキストをチャネルへ表示してはならない (SHALL NOT)。

#### Scenario: 問題のない応答
- **WHEN** エージェントが「テストは3件すべて成功しました」と応答する
- **THEN** 検査の後、そのままのテキストが表示される

#### Scenario: ツール要約も検査する
- **WHEN** ツールの引数に個人情報が含まれる
- **THEN** 進捗表示に出るツールの要約は、検査後のテキストになる

### Requirement: 個人情報はマスクして表示する
システムは、検査で個人情報（機密データ保護のフィルタ）だけが該当した場合、Model Armorが返したマスク後のテキストに置き換えて表示しなければならない (SHALL)。マスク後のテキストが返らなかった場合は、その出力を表示してはならない (SHALL NOT)。

#### Scenario: メールアドレスを含む応答
- **WHEN** エージェントの応答に第三者のメールアドレスが含まれる
- **THEN** メールアドレスがマスクされたテキストが表示される

### Requirement: 個人情報以外のフィルタに該当した出力は表示しない
システムは、検査で個人情報とjailbreak以外のフィルタ（有害コンテンツ、悪性URL、CSAMなど）に該当した出力を表示してはならない (SHALL NOT)。代わりに、ポリシーにより表示できなかったことを出力イベントで返さなければならない (SHALL)。

#### Scenario: 悪性URLを含む応答
- **WHEN** エージェントの応答が悪性URLのフィルタに該当する
- **THEN** 応答は表示されず、ポリシーにより表示できなかったことが通知される

### Requirement: jailbreakの判定では出力を止めない
システムは、出力の検査で、プロンプトインジェクション・jailbreakのフィルタだけに該当した出力を、該当しなかったものとして表示しなければならない (SHALL)。無視するフィルタは設定で変更できなければならない (SHALL)。

#### Scenario: シェルコマンドの要約
- **WHEN** ツールの要約`echo hello > a.txt && cat a.txt && whoami`がjailbreakのフィルタだけに該当する
- **THEN** 要約はそのまま表示される

### Requirement: 長い出力は分割して検査する
システムは、Model Armorの1回の検査上限を超える長さの出力を、段落またはコードブロックの境界で分割して、すべての部分を検査しなければならない (SHALL)。

#### Scenario: 長い応答
- **WHEN** 検査上限を超える長さの応答が生成される
- **THEN** 応答は分割して検査され、検査されていない部分が表示されることはない

### Requirement: 検査の失敗時は表示しない
システムは、Model Armorの呼出しが失敗した場合、その出力を表示してはならない (SHALL NOT)。検査に失敗したため表示できないことを出力イベントで返さなければならない (SHALL)。

#### Scenario: Model Armorの障害
- **WHEN** Model Armorの呼出しがエラーになる
- **THEN** 出力は表示されず、検査に失敗したことが通知される

### Requirement: エージェントの文脈はマスクしない
システムは、マスクや差し止めをチャネルへの表示だけに適用し、エージェントが参照する会話履歴の内容を書き換えてはならない (SHALL NOT)。

#### Scenario: マスク後の次のturn
- **WHEN** 前のturnの応答がマスクされて表示され、次のturnでその内容について尋ねる
- **THEN** エージェントはマスク前の内容を文脈として参照できる
