## ADDED Requirements

### Requirement: Firestore のバックアップを、ワークロードから読めない専用の保存先に置く
システムは、Firestore のバックアップ（エクスポート）を置く専用の保存先を、コマンド出力などの実行時のデータとは別に用意しなければならない (SHALL)。どのユースケースの、どの役割の Workload Identity にも、この保存先への権限を与えてはならない (SHALL NOT)。保存先は公開を禁止し、バックアップとして足りる保持期間（コマンド出力より長い）を持たなければならない (SHALL)。

#### Scenario: Worker がバックアップを読もうとする
- **WHEN** あるユースケースの Worker の Workload Identity で、バックアップの保存先のオブジェクトを読む、一覧する、書く
- **THEN** すべて権限エラーになる

#### Scenario: 運用者がバックアップを取る
- **WHEN** 運用者が Firestore のエクスポートを、この保存先へ実行する
- **THEN** エクスポートは成功し、保存先のオブジェクトはコマンド出力の保持期間では削除されない

### Requirement: コマンド出力の保存先をユースケースごとに分ける
システムは、コマンド出力の保存先をユースケースごとに用意し、そのユースケースの Worker に読み取り、Sandbox 管理サービスに読み書きだけを許さなければならない (SHALL)。あるユースケースの役割には、別のユースケースの保存先への権限を与えてはならない (SHALL NOT)。

#### Scenario: 別のユースケースの出力を読もうとする
- **WHEN** ユースケース A の Worker の Workload Identity で、ユースケース B のコマンド出力のオブジェクトを読む
- **THEN** 権限エラーになる

#### Scenario: 自分のユースケースの出力を扱う
- **WHEN** ユースケース A の Sandbox 管理サービスが出力を保存し、A の Worker が読む
- **THEN** どちらも成功する
